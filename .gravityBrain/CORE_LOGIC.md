# 🧠 핵심 비즈니스 로직 (CORE_LOGIC)

## 1. 지능형 수집 및 캐싱 (`collector.py`)
- **상세 정보 사전 수집**: 목록 수집 단계에서 `pbancMngNo`를 정확히 식별하여 상세 텍스트(`cltrDtlCont`)를 미리 DB에 저장. AI 분석 단계에서의 API 호출 병목 현상 해결.
- **필드 매핑 최적화**: 온비드 API의 공고번호와 관리번호 간의 매핑 오류를 수정하여 상세 데이터 수집 성공률 극대화.

## 2. AI 분석 파이프라인 (`ai_analyzer.py`)
- **Stage 1 (Maverick)**: `Llama 3.1 8B` 모델을 활용한 50개 단위 고속 필터링.
- **Stage 1.5 (Selective Classifier)**: 
  - **일괄 매각 탐지**: 정규식(`외\d+건`, `일체`, `\d+개` 등)을 통해 패키지 매물을 식별하여 분석 보류.
  - **정보 부족 탐지**: 텍스트 길이 및 '첨부파일 참조' 키워드 검색을 통해 분석 불가 매물을 `Hold` 처리.
- **Stage 2 (Deep Dive)**: 
  - 분석 적합 매물에 대해서만 `Llama 3.1 8B` (JSON 모드) 호출.
  - **수익성 정밀 산출**: 중고 장터 시세 추정치에서 입찰가와 부대비용(수리, 탁송 등)을 제외한 실질 순수익 계산.
  - **한국어 리포트**: 모든 요약문과 분석 결과는 한국어로 고정 출력.

## 3. 프론트엔드 데이터 서빙
- **SSG 기반 데이터 로드**: `export_data.py`가 생성한 `items.json`을 통해 서버 부하 없이 실시간 필터링 및 탭 전환 지원.
- **분석 상태 시각화**: `ai_difficulty = 'Hold'`인 매물은 상세 페이지에서 '상세 정보 부족으로 인한 분석 보류' 메시지를 표시하여 사용자 오해 방지.
