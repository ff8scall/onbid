# 🧠 핵심 비즈니스 로직 (CORE_LOGIC)

## 1. 실시간 수집 로직 (`collector.py`)
- **키워드 기반 필터링**: 노트북, 컴퓨터, 서버 등 핵심 키워드를 포함한 공고만 선별.
- **이미지 연동**: 목록 API의 `thnlImgUrlAdr` 필드를 활용하여 실물 썸네일 확보.

## 2. AI 분석 및 스코어링 (`ai_analyzer.py`)
- **로컬 휴리스틱 엔진 (Fallback)**:
  - **신뢰도 점수**: 연구소/교육기관/법원 배출 매물에 가중치 부여.
  - **수량 리스크**: 대량 일괄 매각 건에 대해 감점 처리.
  - **0-100 클램핑**: 최종 점수를 시각적으로 균일하게 보정.
- **AI 프롬프트 전략**: 상세 설명 텍스트에서 CPU 세대, 하드웨어 하자, 인도 방법(송파구 기준) 등을 추출.

## 3. 프론트엔드 시각화
- **실시간 라이브 스캔**: 대시보드 상단에 활성화 상태 표시.
- **다이렉트 입찰 연동**: 온비드 공식 상세 페이지(`collateralDetailInfo.do`)로의 딥링크 생성.
