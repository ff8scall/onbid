# 🧠 핵심 비즈니스 로직 (CORE_LOGIC)

## 1. 실시간 수집 로직 (`collector.py`)
- **키워드 기반 필터링**: 노트북, 컴퓨터, 서버 등 핵심 키워드를 포함한 공고만 선별.
- **이미지 연동**: 목록 API의 `thnlImgUrlAdr` 필드를 활용하여 실물 썸네일 확보.

## 2. AI 분석 및 스코어링 (`ai_analyzer.py`)
- **2단계 깔때기(Funnel) 아키텍처**:
  - **Stage 1 (Maverick)**: `Llama 3.1 8B` 모델을 사용하여 50개 단위로 매물을 배치 분석. 저가치 매물을 빠르게 솎아내어 토큰 및 비용 최적화.
  - **Stage 2 (Deep Dive)**: `Stepfun 3.5 Flash` 모델을 사용하여 선별된 정예 매물의 상세 텍스트(최대 4000자) 분석. 시장가 추정, 리스크(하자), 리셀 요약문 생성.
- **JSON 파싱 최적화**: NVIDIA NIM 모델별 특성에 맞춰 `json_object` 모드 지원 여부에 따른 동적 대응 로직 적용 (Stepfun의 경우 Regex 기반 JSON 추출).
