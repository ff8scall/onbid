# 📝 작업 메모리 (MEMORY)

## 1. 최근 작업 완료 사항 (2026-05-03)
- **손익분기점(Break-even) 기반 필터링 도입**: 
  - AI가 `Estimated Market Price - Costs`로 손익분기점을 먼저 계산하도록 프롬프트 고도화.
  - 최저입찰가가 손익분기점을 초과하는 매물을 자동으로 `Substandard` 처리하는 로직 반영.
- **단건 매물(보석, IT) 분석 강화**:
  - 보석류(감정가 기반)와 IT 기기(사양별 실거래가 기반)의 수익성 산출 공식을 정밀화.
  - 마진율 20% 이상인 매물에만 85점 이상의 고득점을 부여하여 '정예 매물'의 퀄리티 확보.
- **데이터 중복 처리 및 AI 고도화 (2026-05-04)**:
  - Upsert(`ON CONFLICT`) 로직 도입으로 중복 리스트 노출 문제 해결.
  - 가격 변동 시에만 AI 재분석 수행 (리소스 최적화).
  - **차액 발생 근거(Price Gap) 분석 (New)**: 단순 마진 계산을 넘어, 왜 해당 매물이 시세 대비 저렴하게 낙찰될 가능성이 있는지(인지도 부족, 특정 브랜드 프리미엄, 시장 트렌드 등)에 대한 구체적인 사유를 추출하여 보고서에 포함.
- **가독성 특화 UI (New)**: 메인 페이지에서는 AI가 생성한 '한 줄 캐치프레이즈'로 매력을 어필하고, 상세 페이지에서 심층적인 'AI Profit Logic'을 시각적으로 아름답게 구현.
- **메뉴별 지능형 정렬 시스템 (2026-05-07)**:
  - 전 메뉴(정예, 후보, 미달, 종료)에 수익금/마감일/스코어순 정렬 UI 통합.
  - 탭 전환 시 메뉴 성격에 맞는 기본 정렬값 자동 적용 (정예: 수익금순, 후보: 스코어순, 종료: 최근종료순).
  - Glassmorphism 기반의 프리미엄 정렬 컨트롤러 UI 구현.
