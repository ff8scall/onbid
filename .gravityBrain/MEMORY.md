# 📝 작업 메모리 (MEMORY)

## 1. 최근 작업 완료 사항 (2026-05-03)
- **손익분기점(Break-even) 기반 필터링 도입**: 
  - AI가 `Estimated Market Price - Costs`로 손익분기점을 먼저 계산하도록 프롬프트 고도화.
  - 최저입찰가가 손익분기점을 초과하는 매물을 자동으로 `Substandard` 처리하는 로직 반영.
- **단건 매물(보석, IT) 분석 강화**:
  - 보석류(감정가 기반)와 IT 기기(사양별 실거래가 기반)의 수익성 산출 공식을 정밀화.
  - 마진율 20% 이상인 매물에만 85점 이상의 고득점을 부여하여 '정예 매물'의 퀄리티 확보.
- **데이터 중복 처리 및 AI 고도화 (2026-05-04)**:
  - Upsert(`ON CONFLICT`) 로직 도입으로 중복 리스트 노출 문제 해결.
  - 가격 변동 시에만 AI 재분석 수행 (리소스 최적화).
  - AI 분석 보고서에 '수익 발생 근거(Price Gap)' 상세 설명 추가.
