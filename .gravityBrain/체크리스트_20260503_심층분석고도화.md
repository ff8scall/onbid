# ✅ 체크리스트: 정밀 분석 타겟 세분화 및 심층 수익성 분석 고도화

## 1. 분석 및 설계 (MASC)
- [ ] **PM**: "분석 불가능한 건(일괄, 상세누락)"과 "분석 가능한 단건"을 분리하여 리포트의 신뢰도(Quality)를 극대화. 억지로 추론하여 발생하는 할루시네이션(환각) 방지 및 API 비용 절감.
- [ ] **Architect**: 
    - `ai_analyzer.py` 내에 매물 유형 판별 로직 추가 (단건 vs 일괄매각 vs 정보누락).
    - 분석 불가 건은 Llama API 호출 없이 '보류(Hold)' 상태로 즉시 DB 업데이트.
    - 단건/정보충분 매물은 프롬프트를 강화하여 '예상 시세 - 입찰가 - 부대비용 = 순수익' 구조의 심도 있는 재무 분석 수행.
- [ ] **Security**: 불필요한 빈 데이터 API 호출 차단으로 Rate Limit 및 비용 보호.

## 2. 코드 수정 (`backend/ai_analyzer.py`)
- [ ] **유형 판별기(Classifier) 함수 추가**:
    - 물건명 정규식 분석 ('외 N건', '일체', '등', 복수 수량 등) -> `is_bundle`
    - `detail_text` 길이 및 특정 키워드('첨부파일 참조' 등) 분석 -> `is_missing_info`
- [ ] **Stage 2 (Deep Dive) 로직 분기**:
    - `is_bundle` 또는 `is_missing_info` True일 경우: API 호출 생략, `ai_score=0`, 상태 '보류(Hold)'로 기록.
    - False(분석 적합)일 경우: 심층 프롬프트로 Llama 3.1 8B 호출.
- [ ] **심층 분석 프롬프트 고도화**:
    - 중고 시세 추정 근거 요구.
    - 부대비용(수리비, 탁송비 등) 감안한 보수적인 `expected_profit` 산출 지시.

## 3. 프론트엔드 연동 (`export_data.py` 및 UI)
