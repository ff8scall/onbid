# ✅ 체크리스트: 손익분기점 기반 필터링 및 단건 매물 분석 강화

## 1. 분석 및 설계 (MASC)
- [x] **PM**: "단품(보석, 컴퓨터)" 위주의 고수익 매물 집중. 최저입찰가가 손익분기점을 넘어서는 매물은 과감히 배제.
- [x] **Architect**: 
    - AI 프롬프트에 `break_even_price` 계산 로직 명시.
    - `min_bid_price`와 `break_even_price`를 비교하여 점수 산정 및 필터링.
    - 첨부파일 가독성 한계를 인정하고 '일괄 매각(Bundle)' 건은 기존처럼 보류 유지.
- [x] **Security**: 변화 없음.

## 2. 코드 수정 (`backend/ai_analyzer.py`)
- [x] **프롬프트 고도화**:
    - `Market Price` (감정가+실거래가 기반)와 `Costs`를 기반으로 `Break-even Point`를 정의하도록 지시.
    - `Profit Margin = Break-even - Min Bid`를 명확히 산출하도록 요구.
- [x] **필터링 로직 강화**:
    - `ai_score` 산정 시 마진율이 낮거나 손해 구간인 경우 60점 미만(Substandard)으로 자동 분류.
